  Welcome to version 1.0 of Radware. To Install, first quit windows if you are
in windows. 2nd, change drives to the floppy containing the install disk 
file (Example A:) & type install. During the installation process, this file 
will automatically be displayed again. Installation requires that version 5.0
or greater of DOS be installed on your computer. The installation process will
search for win.com & both dsp001.ld & synth.ld. The .ld files are files that were 
installed when you installed your PSA sound card. If you do not have a PSA 
sound card, the installation software will inform you that it can not find 
these files, and will ask you if you wish to install the program for 
simulation. If you later install an appropriate sound card, you will need to 
reinstall the Radware software. Please note that this software will be in a 
simulation mode anytime a RADWARE card is not plugged in.
