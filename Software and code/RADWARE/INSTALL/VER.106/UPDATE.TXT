Version 1.06 (3/10/95)

Additions
  9 Channel quick memmories has been moved under stations, & there are
    now 9 banks of channels.
  Added check to make sure a window has not moved beyond the screen
    limit, and return it into the screen area if it has.
  S Meter is now calculating out the Analog Gain and the RF AMP/ATTN
  AGC no longer access the RF AMP/ATTN or the Analog Gain when in AM.
    The overhead of AGC & AM Tuning is too much for any computer except
    the pentium. This will return once the algorithms have been sped up.

Version 1.05 (3/8/95)

Problems noted by Jim Gorman
  LSB was allowed to enter 16KHz filter. This has been removed

Problems
  SMeter was looking at the weakest sideband. Now looks at strongest
    applicable sideband.
  AGC had the same problem as the s meter.

Additions
  9 Channel Quick memory channels were added. These were previously in
    the radio menu. To store a channel, set the radio to the appropriate
    settings and press the right mouse button while on the "button" of the
    channel you wish to store it in. The left mouse button on that
    "button" will recall the channel.

Additions
  The RADWARE program now accepts command line parameters. To use these,
    all parameters must be the name of a file WITHOUT any extension. the
    file need not exist. The first extension will control where the places
    of the windows will be kept, and .plc will be appended to it. The
    second extension controls what settings the radio has, and will have
    .set appended to it. If the second parameter is missing, it will default

    to the first parameter. The 3rd parameter will name the file for storing
    the stations in. It will be appended by .sta and will default to the
    first parameter if missing. If there are no parameters, the RADWARE
    program will default to places.plc, settings.set & stations.dat.
    Deleting the appropriate files will cause the RADWARE program to give
    a warning message & the default to standard settings. All files will be
    updated/created at the time that RADWARE is closed.
  Added a check for a corrupt .PLC file. If .PLC is detected as corrupt,
    RADWARE will default.
  Inhibited all transmitions outside of HAM frequencies.
