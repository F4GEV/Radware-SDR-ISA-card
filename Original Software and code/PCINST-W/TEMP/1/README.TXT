
Software Installation:
This version of SETUP.EXE was designed to use within Windows 3.1 and Windows 95.
        A. Using Windows 3.1:
                1. In Program Manager, choose "File" and then choose "Run".
                2. Type "A:\SETUP" in the edit box and click "OK"
                3. Follow the instructions displayed in screen.

        B. Using Windows 95:
                1. Choose "Start" and then choose "Run".
                2. Type "A:\SETUP95" in the edit box and click "OK"
                3. Follow the instructions displayed in screen.

MIDI Mapper configuration in Windows 95:
If you can not hear any music when you play a MIDI file, there may be incorrect
settings in the MIDI Mapper configuration. You can correct this problem by  the
following steps:
        1. Choose "Start" and "Settings" and "Control Panel".
        2. Choose "Multimedia" and choose "MIDI"
        3. In the "MIDI output" List Box, please choose "MIDI for MPU MIDI Out
           / Synth" if you add a Wave table daughter board on your Sound card.
           Otherwise, please choose "MIDI for Voyetra OPL3 FM SS Synth".
