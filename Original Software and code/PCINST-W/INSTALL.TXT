
Two Steps In Using PC-Install
-------------------------------------------------------------------

1) Open one of the sample files PC-Install provides (e.g. basic.cfg,
typical.cfg, or super.cfg) in the PC-Install directory using Notepad 
or any other text editor.  Modify this file to suit your needs and 
save it as file INSTALL.CFG.

2) Copy file INSTALL.EXE and INSTALL.CFG (you just created) to your
floppy disk.

That's all there is to it.  

For more information, refer to the PC-Install manual.
