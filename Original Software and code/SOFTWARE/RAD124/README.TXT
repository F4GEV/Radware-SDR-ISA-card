  Welcome to Radware. To Install, Click on the File menu item in the program
Manager. Then select run. Type in "A:setup". (or "B:Setup" if you disk is
in the B drive. During the installation process, this file will automatically 
be displayed. If you do not have a PSA compatible sound card, the installation
software will install the program for simulation. If you later install an
appropriate sound card, you will need to reinstall the Radware software. 
Please note that this software will be in a simulation mode anytime a PSA
sound card is not plugged in.

  The Radware BBS will have period updates of the RADWARE software. Please 
feel free to download the latest version. Again, comments and questions about
the additional features are welcomed, and the order that new features will be
added will depend on which features are asked for most. Keep in mind that this
Card is almost entirely DSP decoded, and as such, most RF communication forms
can be implemented.
  For those of you who are updating to the latest version, I highly recommend
that you read Update.TXT to see the changes since your last software.
  386 Users: If you are using a 386 or before, opening up multiple analyzers
can cause your computer to hang due to the large quantity of graphics data.
You should probably stick to just 1 or 2 analyzers.
  A file will also be added to the Startup Group in the program manager.
Please do not remove this program from startup unless you remove the RADWARE
card. This program reinitializes the RADWARE card after windows starts. We
found this was required due to some systems reseting all ports when windows
is loaded.
  One last note: It seems that installing RADWARE to the same directory as
you are installing it from will cause large quanties of your hard disk to be
used up. Please install to a different directory than the source or install
directly from the floppy.
